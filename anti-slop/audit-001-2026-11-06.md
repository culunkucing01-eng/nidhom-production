# Antislop Audit: Master Data Guru

Date: 2026-11-06

Design Read: An authenticated admin page for school staff managing teacher records, using the approved Modern Institutional and Academic Navy direction. Dials: ENERGY 1, RHYTHM 2, MOTION 1.

Decision notes:

- Academic Navy stays as the primary color to preserve the approved Nidhom identity.
- The page puts its real task first: search and filter the teacher list, then expose record actions.
- The existing system font and spacing tokens remain in use to preserve readability and the approved system.
- One card groups the list controls and data table; statuses use badges because active state is meaningful record data.
- The short loading spinner communicates pending work and stops under reduced-motion preferences.

## Findings

### 1. HIGH: Em dash in the unavailable-date fallback

- Rule: R-02
- File: `apps/web/src/features/guru/GuruPage.tsx:48`
- Evidence: the invalid-date fallback returns an em dash, which is prohibited in authored UI text.
- Suggested fix: use a short Indonesian text fallback such as `Tidak tersedia`.

### 2. HIGH: Escape does not close the dialog

- Rule: R-32
- File: `apps/web/src/features/guru/GuruPage.tsx:421`
- Evidence: browser testing opened the Add Guru dialog and sent Escape twice; the dialog remained open. The visible close and Batal buttons did close it.
- Suggested fix: make the native dialog cancel event close the dialog and clear its React state, then repeat the keyboard test.

### 3. HIGH: Status select lacks clear interaction affordances

- Rule: R-39
- Files: `apps/web/src/features/guru/GuruPage.tsx:231`, `apps/web/src/features/guru/GuruPage.css:197`, `apps/web/src/styles/global.css:34-51`
- Evidence: browser inspection showed the status select using the default cursor and a thin browser-default focus outline. The theme toggle and danger button also lack distinct pressed/hover feedback.
- Suggested fix: add the select to the shared pointer/focus affordance rules and provide visible active/hover states for the affected controls.

## Follow-up audit: 2026-11-07

The owner approved all three HIGH findings. The Master Data Guru UI changes are complete, and all three findings are closed.

- R-02: the invalid-date fallback now displays `Tidak tersedia`.
- R-32: Escape closes both the add dialog and the status confirmation dialog. Escape does not submit the confirmation action, and clicking `Konfirmasi` still runs the action.
- R-39: the status select has a pointer cursor, hover and active feedback, and a visible keyboard focus ring. Guru buttons have visible hover, active, and focus-visible feedback, including the theme toggle and danger action.
- The new hover and focus states use existing Nidhom theme tokens so the interaction cues remain within the Academic Navy design system.

Verification:

- `npm run build`: passed.
- `npm run lint`: passed.
- Browser test with local mock responses: invalid date showed `Tidak tersedia`; Escape closed both dialogs without a status request; `Konfirmasi` sent one mocked status request and showed its success message; select and button focus-visible states appeared; light-theme select and primary-button hover states changed visibly; no console errors occurred during the mocked interaction run.
- Contrast checks passed for light and dark focus indicators, danger hover text, and primary-button hover text.

No API, database, authentication, or session logic was changed. No deployment, remote D1 access, commit, or push was performed.
