# Antislop Audit: Master Data Kelas

Date: 2026-11-07
Mode: AFTER

Design Read: An authenticated admin page for school staff managing class records, using the user-approved Nidhom v1.0 Modern Institutional and Academic Navy direction. Dials: ENERGY 1, RHYTHM 2, MOTION 1.

Decision notes:

- The Academic Navy palette and existing typography, spacing, and radius tokens preserve the shared Nidhom design system.
- Search and status filtering precede the class table because the main task is finding a record and deciding whether to inspect or edit it.
- The table shows active schedule counts and status because they inform safe class management.
- The native dialog supports focused create, edit, detail, and confirmation tasks without adding another page or dependency.

## Findings

### 1. HIGH: Interactive targets are shorter than the 44px touch target

- Rule: R-03
- Files: `apps/web/src/features/admin/AdminTopbar.tsx:24`, `apps/web/src/features/guru/GuruPage.css:16`, `apps/web/src/features/guru/GuruPage.css:362`
- Evidence: at 768px, the Nidhom brand link measures 29px high. The shared row-action buttons have `min-height: 40px`; their 44px override applies only at widths of 680px and below, so they remain 40px at the requested 768px tablet width.
- Suggested fix: give the brand link and row-action buttons a minimum 44px hit area at tablet and desktop widths as well. Keep the visual hierarchy and shared Guru/Kelas controls unchanged.
- Status: Closed after the owner approved the fix. Kelas-only styles now give the brand link and row-action buttons a 44px minimum height.

### 2. HIGH: The brand link has no distinct hover or active feedback

- Rule: R-39
- Files: `apps/web/src/features/admin/AdminTopbar.tsx:24`, `apps/web/src/features/guru/GuruPage.css:16`
- Evidence: browser inspection at 768px showed the brand link's foreground, background, decoration, and transform unchanged at rest, hover, and press. The link has a visible keyboard focus style, but no pointer-state feedback.
- Suggested fix: add a restrained hover and active treatment to the brand link in Kelas, using existing Nidhom tokens.
- Status: Closed after the owner approved the fix. Kelas-only hover and active states now use existing Nidhom color tokens.
